 Elephant Migration Analysis 

 Analysis of African elephant movement patterns in Etosha National Park, Namibia (2008-2014).

 About
 This project analyzes GPS tracking data of African elephants to understand:
- Seasonal migration patterns (dry vs wet season)
- Correlation between temperature and daily movement distance
- Hotspots and frequently visited locations

 Dataset
- Source: Movebank.org (Tsalyuk et al. 2018)
- 99,988 GPS recordings
- 7 years of data (2008-2014)

 Technologies
- Python, Pandas
- Scipy (Pearson correlation)
- Folium (interactive maps)
- Open-Meteo API (weather data)

 Key Findings
- Elephants move more in wet season (11.4 km/day vs 10.2 km/day in dry season)
- Temperature has very weak correlation with movement (r=0.07)
- Elephants follow the southern edge of Etosha Pan — permanent water sources
